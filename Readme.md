# 💊 MediTrack

MediTrack is a full-stack MERN web application that helps users manage their medicines efficiently by providing medication reminders, stock tracking, and family member management.

## 🚀 Features

- 🔐 User Authentication (JWT)
- 👨‍👩‍👧‍👦 Family Member Management
- 💊 Medicine Management
- ⏰ Daily Medicine Reminders
- 📦 Medicine Stock Tracking
- 🔔 Low Stock Alerts
- 📊 Dashboard
- 📱 Responsive UI

---

## 🛠️ Tech Stack

### Frontend

- Express.js

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Falgun1306/MediTrack.git
```

### Frontend

```bash
cd Client
npm install
npm run dev
```

### Backend

```bash
cd Server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `Server` directory.

Example:

```env
DATABASE_URL=
JWT_SECRET=
EMAIL_USER=
EMAIL_PASS=
```
